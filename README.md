# Hazzaz Store PS4 Multi-Firmware Host

واجهة Hazzaz Store العربية لتشغيل GoldHEN مع اختيار المحرك المناسب تلقائيًا ودعم التخزين دون اتصال.

## الإصدارات المدعومة

- 7.00–8.52
- 9.00–9.60
- 10.00–11.02
- 11.50–12.02
- 12.50–13.00
- 13.02–13.52
- 14.00 عبر Afterglow Web

## المصدر

تعتمد ملفات التشغيل متعددة الإصدارات على مجلد `g2all` من مستودع `gamerhack/gamerhack.github.io` عند المراجعة:

`066f5b456f2fb9da47bfb7f6b9ddc8e599cee30f`

إصدار GoldHEN المضمّن: `v2.4b18.12`، مع محرك التشغيل وملفات الكاش المحدّثة بتاريخ 2026-10-06.

التعديلات الخاصة بـHazzaz Store محصورة في الواجهة، التوجيه حسب الإصدار، رسائل الحالة، الصور، وملفات التخزين. ملفات المحرك الأصلية محفوظة مع إشعارات ترخيصها.

## Afterglow Web — 2026-11-03

أُضيف المصدر الكامل من [well0nez/afterglow-web](https://github.com/well0nez/afterglow-web) عند المراجعة `acf25a831725f0d44fcb64725d4ce35acbba8f9d` داخل مجلد `afterglow/`، مع ملفات GoldHEN وps4-hen وملفات patchset الأصلية. يوجّه الموقع إصدار 14.00 إلى هذا المجلد؛ وتستمر الإصدارات 7.00–13.52 على المحركات والملفات الثنائية السابقة دون تغيير.

يحتفظ المجلد بترخيص AGPL-3.0-or-later وإشعارات MIT في `LICENSE-raw13g`، مع توثيق المصدر في `README.md` و`TECHNICAL.md`. تعديلات الدمج محصورة في هوية Hazzaz Store، لغة الواجهة، منع التشغيل من أجهزة أو إصدارات غير مدعومة، وملف الكاش. صفحة التشغيل تحتفظ بتحميلها الأصلي دون إضافة صور أو ملفات خارجية أثناء الاستغلال.

Afterglow تجريبي ويدعم 13.52 و14.00 فقط؛ الدعم التلقائي في الصفحة الرئيسية مضاف لإصدار 14.00. لم يُختبر الاستغلال على جهاز PS4 في بيئة التطوير.
